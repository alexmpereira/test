# Página HTML com "Olá Jaqueline" com Semântica

Aqui está o código melhorado para criar uma página que mostra "Olá Jaqueline" em um h1 com **estrutura semântica**:

```html
<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="Página de saudação para Jaqueline">
    <title>Olá Jaqueline</title>
</head>
<body>
    <header>
        <h1>Olá Jaqueline</h1>
    </header>
    <main>
        <!-- Conteúdo principal da página -->
    </main>
    <footer>
        <!-- Rodapé da página -->
    </footer>
</body>
</html>
```

**O que faz cada parte:**
- `<!DOCTYPE html>` - Define que é um documento HTML5
- `<html lang="pt-BR">` - Elemento raiz com idioma definido
- `<head>` - Contém metadados e título
- `<meta charset="UTF-8">` - Define a codificação de caracteres
- `<meta name="viewport">` - Torna a página responsiva
- `<meta name="description">` - Descrição para SEO e navegadores
- `<title>` - Título da página (aparece na aba do navegador)
- `<body>` - Contém o conteúdo visível
- **`<header>`** ⭐ - **Semântico**: Define a seção de cabeçalho da página
- `<h1>` - Título de nível 1 (único por página para melhor SEO)
- **`<main>`** ⭐ - **Semântico**: Define o conteúdo principal da página
- **`<footer>`** ⭐ - **Semântico**: Define a seção de rodapé da página

**Por que usar semântica é importante:**
✅ Melhor acessibilidade para leitores de tela
✅ Melhor SEO (otimização para mecanismos de busca)
✅ Código mais legível e manutenível
✅ Estrutura clara para navegadores e assistentes

Salve este código em um arquivo com extensão `.html` e abra no navegador! 😊
