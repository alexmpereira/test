# Implementação de Página com Título "Hello Gazin" - HTML Semântico

Aqui está a página atualizada com HTML semântico:

```html
<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="Página de apresentação Hello Gazin">
    <title>Hello Gazin</title>
    <style>
        body {
            display: flex;
            justify-content: center;
            align-items: center;
            height: 100vh;
            margin: 0;
            background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
            font-family: Arial, sans-serif;
        }
        
        main {
            text-align: center;
        }
        
        h1 {
            font-size: 4rem;
            color: white;
            text-shadow: 2px 2px 4px rgba(0, 0, 0, 0.3);
            margin: 0;
        }
    </style>
</head>
<body>
    <main>
        <header>
            <h1>Hello Gazin</h1>
        </header>
    </main>
</body>
</html>
```

## O que foi atualizado:

✅ **Título HTML** - "Hello Gazin"  
✅ **Design responsivo** - Se adapta a diferentes tamanhos de tela  
✅ **Centralizado** - Título centralizado na página  
✅ **Estilo moderno** - Gradiente de cores e sombra de texto  
✅ **Metadados corretos** - Charset UTF-8 e viewport configurados  
✅ **HTML Semântico** - Uso de tags `<main>`, `<header>` e `<h1>` com propósito semântico  
✅ **Meta description** - Melhor para SEO  
✅ **Estrutura semântica apropriada** - Facilita acessibilidade e indexação por buscadores  

Você pode salvar esse código em um arquivo `.html` e abrir no seu navegador! 🎉
